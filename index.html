📅 Design Log · 设计迭代记录

周六上午 需求分析与初步设计

讨论目标用户痛点，确定核心功能：定时提醒 + 体育课后特殊提醒。初步选定 ESP32 + OLED + 蜂鸣器方案。

📸 失败/迭代记录： 最初的提醒方式只有蜂鸣器，测试后发现容易忽略，后续增加了 OLED 显示提醒。
周六下午 硬件搭建与代码调试

完成 ESP32 与 OLED、蜂鸣器的接线。编写定时器代码，实现每 45 分钟触发提醒。

📸 失败/迭代记录： 第一次接线时 OLED 不亮，排查发现是 I2C 地址错误（0x3C vs 0x3D），修改后正常。
周日早晨 功能完善与外壳适配

完成体育课后特殊提醒逻辑，与 3D 打印外壳进行适配组装，整机测试。

📸 失败/迭代记录： 外壳尺寸与电路板不匹配，需微调螺丝孔位；蜂鸣器音量偏小，最终通过增加 PWM 占空比优化。

核心代码片段
// 定时提醒核心逻辑（每45分钟）
#include <U8g2lib.h>
#include <WiFi.h>

U8G2_SSD1306_128X64_NONAME_1_SW_I2C u8g2(U8G2_R0, /*clock=*/22, /*data=*/21, /*reset=*/U8X8_PIN_NONE);

unsigned long lastRemindTime = 0;
const unsigned long REMIND_INTERVAL = 45 * 60 * 1000; // 45分钟

void setup() {
  u8g2.begin();
  pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
  unsigned long now = millis();
  
  // 定时提醒
  if (now - lastRemindTime >= REMIND_INTERVAL) {
    lastRemindTime = now;
    remindToDrink();  // 触发提醒：蜂鸣器 + OLED显示
  }
  
  // 体育课后特殊提醒（13:00-15:00时间段额外检查）
  if (isAfterPEEdTime()) {
    sportsRemind();
  }
}

🤔 Reflections · 硬核 Bug 与解决方案

🐛 Bug 1：OLED 显示屏无显示

接线完成后 OLED 完全不亮，排查了电源、接线顺序都没问题。

✅ 解决方案： 使用 I2C 扫描程序发现地址是 0x3D，而代码默认使用 0x3C，修改地址后正常显示。
🐛 Bug 2：蜂鸣器声音太小

整点报时和提醒时蜂鸣器声音很小，在嘈杂环境中几乎听不见。

✅ 解决方案： 将数字输出改为 PWM 模拟输出，提高占空比到 80%，音量明显提升。同时调整了音调频率使其更悦耳。
🐛 Bug 3：3D 打印外壳与电路板不匹配

外壳打印完成后，发现螺丝孔位偏移约 2mm，OLED 窗口位置也对不齐。

✅ 解决方案： 在 Fusion 360 中重新测量电路板尺寸，调整模型后重新打印。最终版本增加了定位柱，避免再次偏移。
📌 总结：通过三次迭代，解决了硬件、软件、结构三个层面的问题，最终产品稳定运行。
